# Requirements Traceability

![Requirements Traceability logo](logo.png)

Connect requirements, implementation, and tests in a project you can inspect in VS Code.

Use the Requirements view to open, save, or reload a project. Expand a project and source to navigate to its artifacts and links.

The dashboard brings coverage, the traceability matrix, configuration, and diagnostics together. Coverage reports detected links; review the source evidence before treating it as verification.
